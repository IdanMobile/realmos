# RealmOS — First Demo Scenario v1

## Demo Name

Idea to AI Company

## User Prompt

> Jarvis, I have an idea for a real-time dating app. I want us to build it. Create the ecosystem business and prepare the first spec.

## Expected Jarvis Behavior

Jarvis should:

1. Acknowledge the idea.
2. Create an idea intake summary.
3. Ask Council internally if needed.
4. Create a new business named `Real Time Dating App`.
5. Ask Necromancer to create a default agent team.
6. Generate initial artifacts.
7. Show dashboard status.
8. Explain next approval/action.
