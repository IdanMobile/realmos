# RealmOS — Open Questions Register v1

These are not blockers now, but should be answered later.

## Hardware

- What dedicated machine specs will be used?
- Mac, Windows, Linux?
- How much RAM/GPU?
- Always-on location?

## LLM

- Which local model first?
- Which online model provider?
- What is the first monthly budget?
- Should online use require approval by default?

## UI

- Next.js only or desktop wrapper later?
- When to introduce game-like world?
- Should World Visual Agent generate UI layouts?

## Tools

- First real tool: filesystem, terminal, GitHub, browser, or n8n?
- Should terminal start as dry-run only?
- Should browser use a separate profile?

## Memory

- Should memory review be manual weekly?
- Should sensitive memories require confirmation?
- Should business memory ever inherit global memory?

## Agent Behavior

- How often should agents self-review?
- Should agents have personality prompts?
- What metrics define a “bad” agent?

## Product Direction

- Personal-only first?
- Founder/company builder later?
- Enterprise governance later?
- What should be public/private if this becomes a product?
