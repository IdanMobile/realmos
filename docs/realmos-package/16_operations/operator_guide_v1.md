# RealmOS — Operator Guide v1

This guide describes how the user should operate RealmOS once MVP exists.

## Daily Use

Ask Jarvis:

- What needs my attention?
- What agents are blocked?
- What approvals are pending?
- What changed since yesterday?
- What did we decide recently?
- What is the cost this month?

## Creating a Business

Prompt:

> Jarvis, I have an idea for [idea]. Create an ecosystem business and prepare the first spec.

Jarvis should:

- summarize idea
- create business
- create team
- generate artifacts
- show approvals
- update dashboard

## Reviewing Approvals

The user should review:

- cost
- requesting agent
- action
- risk level
- exact payload
- rollback plan

Never approve unclear actions.

## Memory Review

Periodically ask:

> Jarvis, show me new memories from this week.

Then:

- keep
- edit
- delete
- move to business memory
- mark sensitive

## Cost Review

Ask:

> Jarvis, show model/tool costs by business and agent.

Watch for:

- online model overuse
- repeated failed tasks
- unnecessary agents
- subscriptions

## Agent Review

Ask:

> Jarvis, which agents are performing badly?

Review:

- task success
- cost
- mistakes
- blocked status
- duplicate roles

Necromancer can recommend improving or retiring agents.

## Safety Rule

Do not enable:

- email sending
- subscriptions
- crypto trading
- camera/mic
- production deployment

until the governance layer is tested.
