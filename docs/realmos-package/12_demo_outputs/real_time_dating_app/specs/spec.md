# Spec — Real Time Dating App MVP

## Feature Summary

Create an MVP for a dating app focused on real-time availability and high-intent matching.

## User Stories

### US-01: Set availability

As a user, I want to mark myself available now or soon so I can match with people who are also actively available.

### US-02: Discover active matches

As a user, I want to see people who are currently active and relevant to my preferences.

### US-03: Express intent

As a user, I want to indicate whether I want to chat, plan a date, or meet soon.

### US-04: Safety flow

As a user, I want safety controls before sharing sensitive details or meeting.

### US-05: Match conversation

As a user, I want a clean chat flow after mutual intent.

## MVP Functional Requirements

- account/profile
- availability status
- matching feed
- intent indicator
- mutual match
- chat
- report/block
- basic safety prompts
- admin moderation basics

## Non-Goals

- complex AI matching
- full event marketplace
- payments
- video calls
- global launch
- autonomous date planning
