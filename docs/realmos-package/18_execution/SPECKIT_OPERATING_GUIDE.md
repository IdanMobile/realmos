# SpecKit Operating Guide

The active Cursor control file is:

```text
CURSOR_SSOT.md
```

SpecKit is still required, but Cursor must use `CURSOR_SSOT.md` to determine active phase, allowed work, stop conditions, and report format.

## SpecKit Rule

Every implementation task must map to:

- a requirement
- a task
- an acceptance gate
- a verification command or test

If the mapping is unclear, stop and ask for approval before changing architecture or scope.
