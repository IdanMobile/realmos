# RealmOS — UI Screen Inventory v1

## MVP Screens

### 1. Command Center

Main dashboard.

Panels:

- Jarvis briefing
- businesses
- active agents
- task status
- approval queue
- budget/cost
- memory summaries
- recent activity
- simple world preview

### 2. Businesses

List and manage ecosystem businesses.

Features:

- create business
- filter by type/status
- open business detail
- see health/metrics/tasks/agents

### 3. Business Detail

Inside one ecosystem business.

Panels:

- mission
- CEO/PM
- agent team
- tasks
- specs/artifacts
- risks
- memory
- costs
- decisions
- activity

### 4. Agents

List all agents.

Features:

- global agents
- business agents
- agent status
- model profile
- permissions
- assigned tasks

### 5. Agent Detail

Features:

- directive
- tools
- memory access
- limitations
- reports
- tasks
- performance

### 6. Tasks

Task board.

Columns:

- todo
- running
- blocked
- review
- done

### 7. Approvals

Approval queue.

Features:

- approve
- reject
- inspect payload
- see risk
- see cost
- see requesting agent
- audit history

### 8. Memory

Memory manager.

Features:

- global/business/agent/task filters
- summaries
- create/edit/delete
- sensitivity
- retention

### 9. Costs

Budget and cost dashboard.

Features:

- global monthly budget
- per business cost
- per agent cost
- model/tool spend
- subscription requests

### 10. World

Simple v0 world map.

Features:

- business nodes
- agent rooms/cards
- status indicators
- no characters yet

### 11. Settings

Features:

- models
- budgets
- permissions
- tool flags
- storage paths
- local runtime status
