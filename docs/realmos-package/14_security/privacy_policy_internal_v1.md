# RealmOS — Internal Privacy Policy v1

## Privacy Principle

Private user data should be accessible only when needed, scoped, logged, and approved.

## Data Classes

### Public

Examples:

- public web research
- open-source docs
- public product info

### Internal

Examples:

- generated specs
- project tasks
- agent notes
- business dashboards

### Private

Examples:

- personal preferences
- conversations
- local files
- photos
- calendar
- emails
- relationship/person info

### Sensitive

Examples:

- passwords
- tokens
- financial accounts
- crypto keys
- health/legal data
- private identity documents

## Rules

- Sensitive data should not be stored unless explicitly needed.
- Secrets/API keys must not be written into memory.
- Agents need scoped memory access.
- User can delete/edit memory.
- Business memory should not leak into unrelated businesses unless user/Jarvis explicitly allows it.
- External tools must not receive private memory unless required and approved.
- Camera/mic access requires explicit activation and approval.
