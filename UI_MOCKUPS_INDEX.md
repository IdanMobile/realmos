## Implementation note for Cursor

When implementing UI, keep the result:
- clean
- not too busy
- dark but readable
- premium / futuristic
- consistent across all tabs
- aligned with the TDD + ADD + Stop-Check workflow already defined in this repo
- componentized so screens can evolve later into a more game-like world layer without rewriting the base admin experience
